# Страницы подборки и карта

Новый подбор по умолчанию содержит до 30 реальных вариантов. Браузер показывает их по десять: переключатели с номерами, стрелками и диапазоном предложений находятся над карточками и под ними. Если найдено меньше, страниц соответственно меньше. Явная просьба пользователя, например «выбери три», сохраняет указанное количество. Сохранённый размер прежнего подбора не изменяется автоматически; его можно расширить запросом «покажи 30 вариантов».

Переключение страницы выполняется в браузере без вызова модели, нового поиска и изменения профиля. Отметки хранятся отдельно от видимых карточек и сохраняются при переходе между страницами. Нумерация квартир сквозная: на второй странице 11–20. Новый результат сбрасывает просмотр на первую страницу.

При отправке сообщения браузер передаёт ID видимых квартир и ревизию подборки. Сервер проверяет принадлежность объектов этому снимку. Сравнение «среди этих» и контекст объяснения используют открытую страницу; запрос по всему пулу остаётся отдельной областью. Устаревшая ревизия получает понятный ответ с просьбой повторить запрос по актуальной подборке. Согласие звонить при просмотре страниц не возникает.

«Показать на карте» приближает выбранную квартиру до масштаба района, выделяет метку и открывает подпись. Карта относится к текущей странице, переход ждёт её готовности. Метка на карте по-прежнему возвращает к карточке. Без координат кнопка явно сообщает об их отсутствии; координаты не выдумываются по адресу. Существующие запасная подложка и сообщение о недоступности карты сохранены.

Проверки: регрессии сравнения по странице, защиты от чужих и устаревших ID, контекста объяснения и сохранения явного количества; браузерный сценарий `tests.e2e.selection_pages_ui` на 1440/390 px проверяет три страницы, сквозные номера, лайки, отсутствие POST при просмотре, реальную метку Leaflet, отправляемый контекст, короткую выдачу и отсутствие координат. Внешние телефонные звонки не выполняются.
