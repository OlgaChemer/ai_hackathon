# Контекст исследователя и выбранная квартира без общего бюджета

## Переполнение Nanobot

Исследование 150 объявлений завершалось до первого запроса к модели:
`ContextWindowExceededError: 31735/26880 via heuristic`. Nanobot без токенизатора
оценивает запрос консервативно по UTF-8-байтам. Начальное сообщение и функция
сжатия повторяли полную таблицу `facts.rows`; сжатая история также не помещалась.

Начальный запрос теперь содержит ограниченный обзор агрегатов. При сжатии
используется общий предел 6500 байт, история уточнений — до 4200 байт. Числа
в обзоре не пересчитываются моделью. Все строки и исходная история остаются
в `/input/data.json`, а исходные таблицы Excel/CSV формируются по полной выборке.
Вывод Python сохраняется в файле расчёта; сжатие не требует повторного чтения
всего JSON в контекст. Локальный предел 32000 не повышен; резерв ответа приведён
к фактическим 2400 токенам серверного шлюза.

Обновление требует нового образа `mesto-workshop:0.4.2` (пакет nanobot-ai
остаётся версии 0.4.1). При заданном `WORKSHOP_IMAGE` нужно переключить и эту
настройку: один перезапуск backend старый контейнер не обновляет.

`tests.e2e.workshop_context_runtime` запускает настоящую песочницу и Nanobot
с поддельной моделью на сохранённом входе из 150 объявлений. Старый образ
воспроизводит переполнение; новый делает четыре Python-расчёта, проходит
сжатие и сохраняет 150 строк исходных объявлений в Excel. Платных запросов нет.

## Выбор объекта при неизвестном бюджете

В затронутом диалоге бюджет не был назван. После выбора квартиры и заполнения
семьи агент продолжал требовать общий бюджет, хотя цена объекта уже известна.

Для единственной выбранной квартиры подтверждение рамок предлагает её цену
и адрес: клиент принимает либо изменяет потолок. До решения цена объявления
не записывается как разрешённый лимит. При принятии подходящего лимита
сохраняются выбранная квартира и подборка, затем продолжается ипотечная анкета.
Отказ не создаёт согласия; уменьшение лимита ниже цены отзывает выбор для звонка.
Общее уточнение бюджета в этой ситуации недоступно агенту.

Первое заполнение финансовой анкеты больше не сообщает о пересчёте прежнего
плана, если такого плана не было. Изменение существующего расчёта по-прежнему
сбрасывает его и требует пересчёта.

Проверки: 519 Python-тестов, 47 JavaScript-тестов, 128 команд нагрузочного
сценария; отдельная контейнерная регрессия и браузерный переход выбора объекта
к ипотечной анкете на 1440/390 px.
