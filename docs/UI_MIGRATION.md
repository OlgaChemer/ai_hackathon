# Перенос оформления из ux/ui

02.11.2026. Источник: ветка `ux/ui`, коммит `dcf5351`. Получатель: `all_branch` после `cd64c79`.

Перенесены стили `approved-design.css`, оформление подтверждений в основной области, финансовых карточек, результатов поиска и таблицы критериев квартиры. Все файлы находятся в штатном `frontend/`; исходная ветка, внешняя папка дизайна и отдельная сборка для работы не требуются.

Подтверждения остаются теми же карточками: поля, значения, подписи действий и POST-запросы сохраняются. После решения карточка переносится в историю чата; значения формы доступны в раскрывающемся блоке «Параметры решения» без возможности повторной отправки. Голосовой режим ищет активную карточку в новой области. История SSE восстанавливает активные и принятые решения. На телефоне для текстового уточнения есть кнопка «Написать ответ», раскрывающая существующий чат.

Изменения поведения из дизайнерской ветки не переносились:

- Поиск с главной по-прежнему запускается сразу, без дополнительного подтверждения входного запроса.
- Ипотечные расчёты сохраняют прежние числа, статусы и действия; новых команд выбора сценария или пересчёта анкеты нет.
- Названия кнопок звонка и их голосовые команды сохранены, как и темп реплик, телефония и обработка аудио.
- Экономика банка доступна во вкладке. Навигация по всем этапам сохранена в компактном раскрывающемся списке «Этапы сделки»; данные этапов доступны и при открытой карточке решения.
- Backend, API, настройки, защита и ограничения работы агента не менялись.

## Проверка

Проверки выполняются с тестовой моделью и сохранёнными объявлениями через настоящий backend. Для изоляции телефонии тестовый сервер следует запускать с `EXOLVE_API_KEY=`. Нужны настроенное Python-окружение, Playwright и установленный Chromium.

```bash
EXOLVE_API_KEY= .venv/bin/python -m tests.e2e.server --port 8794

.venv/bin/python -m tests.e2e.browser_flow --base http://127.0.0.1:8794
.venv/bin/python -m tests.e2e.ui_regressions --base http://127.0.0.1:8794
.venv/bin/python -m tests.e2e.design_contract --base http://127.0.0.1:8794 --shots /tmp/ui-migration
```

`design_contract` проверяет ширины 1440 и 390 px: запуск с главной без дополнительной сессии, восстановление активной карточки после перезагрузки, редактирование бюджета, голосовое подтверждение, семью/маткапитал и финансовую анкету, архив решений, сохранение чисел ипотечного расчёта, доступ к финансовому плану и экономике без новых команд агенту, а также экранирование текста в таблице критериев. Карта и микрофон в этих проверках подменены; это не проверка настоящего телефонного звонка.

Результат локальной проверки 02.11.2026: 26/26 проверок полного браузерного сценария, 4/4 группы UI-регрессий и обе ширины в `design_contract` прошли. Синтаксис изменённых JS-модулей и `git diff --check` проверены. Эта версия на сервер в рамках переноса не развёртывалась.
