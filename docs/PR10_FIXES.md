# Исправления замечаний к PR №10

Ветка `fix/pr10-review` основана на проверенном коммите `f86b74d` ветки
`olga/pr-fixes`. Исходная ветка PR не изменяется.

## Поведение после исправления

1. В карточке семьи кнопки наличия маткапитала и поле его суммы имеют разные
   селекторы. «Нет» отправляет ноль; «Есть» открывает редактируемую сумму.
2. Выбор конкретной квартиры передаёт её ID. Согласие разрешает звонок только
   по ней, даже если в понравившихся есть другие объекты. Общая кнопка звонка
   сохраняет прежний режим по всем отметкам. Поддельный или устаревший ID
   отклоняется до принятия решения.
3. Первоначальный взнос — собственные деньги плюс маткапитал, не больше цены
   квартиры. Нулевой взнос остаётся нулевым; скрытой подстановки 5% или 20% нет.
   Семейная программа также проверяет достаточность минимального взноса.
4. Изменение наличных сбрасывает прежний финансовый расчёт и план сделки,
   в том числе при одновременном изменении фильтров. Взнос включён в ключ кэша;
   прежний сохранённый расчёт с несовместимым ключом не используется.
5. Программы, платежи в подборке и план покупки используют один расчёт взноса.
   План учитывает согласованную цену объекта. В панели реальный взнос показан
   первым; сравнительные сценарии обозначены отдельно. Кэш карточек обновляет
   платежи после изменения финансирования.
6. Нетронутый ползунок сохраняет точную сумму, включая 8 760 000 ₽ и нулевую
   нижнюю границу. Только перемещаемый ползунок округляется по шагу; стрелки
   клавиатуры работают. Нижняя граница не превышает верхнюю.
7. Пропуск взноса сохраняется и позволяет продолжить подбор без выдуманного
   платежа. Агент повторно открывает вопрос по явной просьбе, а расчёт
   возобновляется после сообщения суммы.
8. Изменение фильтра апартаментов перестраивает пул из исходных объявлений,
   возвращая ранее скрытые варианты.
