# Агент сделки — ИИ-агент «жизненных событий» для Домклик

Прототип для хакатона (номинация ROI). Человек пишет «ищу 2-комнатную до 9 млн», а агент сам проходит путь до сделки: разбирает запрос, считает бюджет и ипотеку, ищет и ранжирует объекты, считает справедливую цену, проверяет юридическую чистоту, звонит продавцу и торгуется, организует просмотр и собирает план сделки. Клиент подтверждает только ключевые решения.

- Разбор идей команды и что из них важно для реализации — [docs/IDEAS.md](docs/IDEAS.md)
- Пути развития — [docs/ROADMAP.md](docs/ROADMAP.md)

## Запуск

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env        # вписать DEEPSEEK_API_KEY (или GigaChat)
.venv/bin/uvicorn backend.main:app --reload
```

Откройте http://127.0.0.1:8000. Лучше в Chrome: там есть синтез и распознавание русской речи.

Без интернета и ключа: `LLM_PROVIDER=mock .venv/bin/uvicorn backend.main:app` — весь сценарий пройдёт на правилах и сценарном торге.

Тесты (без сети): `.venv/bin/python -m unittest discover -s tests -v`

## Сценарий демо (≈ 2 минуты)

1. Нажать пример «Ищу 2-комнатную до 9 млн рядом со школой…».
2. Подтвердить «красные линии» (бюджет, лимит агента) и согласие на данные.
3. Показать короткий список, коридор справедливой цены, проверку: самая дешёвая квартира (ул. Рихарда Зорге, 8,3 млн) отсеяна — арест ФССП и продажа по доверенности.
4. «Звонить — продавца играет ИИ» (или «продавец я», и человек из жюри торгуется голосом/текстом). Счётчик показывает, как падает цена; маркеры агента и продавца сходятся на линейке.
5. Подтвердить цену → просмотр → план сделки → итог: экономия клиента и что получает Сбер.
6. Вкладка «Экономика для Сбера»: ползунки допущений, ROI по сценариям.

## Архитектура

```
frontend/              статичный UI без сборки (HTML + CSS + ES-модули)
  js/app.js            контроллер: SSE-события -> чат, степпер, панели
  js/call.js           экран звонка: счётчик, линейка цены, расшифровка
  js/voice.js          speechSynthesis + webkitSpeechRecognition
backend/
  main.py              FastAPI: API + раздача фронтенда
  llm/                 единый интерфейс LLM
    base.py            LLMClient.chat()/chat_json(), Tool, ToolCall, повторы запросов
    deepseek.py        OpenAI-совместимый API
    gigachat.py        OAuth-токен, tools -> functions, 401 -> обновление токена
    offline.py         офлайн-режим (агент переходит на правила)
    factory.py         выбор по LLM_PROVIDER, откат в офлайн
  agent/
    orchestrator.py    9 шагов, 5 подтверждений клиента, очередь событий
    negotiation.py     торг: LLM-реплики + жёсткие рамки в коде + сценарная стратегия
    tools.py           ипотека, поиск, справедливая цена, юр. проверка, план сделки
    data.py            синтетические данные (объявления, ЕГРН, сделки-аналоги)
    prompts.py         промпты
  economics.py         юнит-экономика и ROI
  data/                listings.json, egrn.json
tests/                 GigaChat-адаптер на моках, рамки торга, экономика
```

Принцип: **числа считает код, LLM только разговаривает.** Справедливая цена, бюджет, платёж и риски детерминированы и объяснимы. В торге модель формулирует реплики, а код не даёт агенту предложить больше лимита клиента или отступить назад, а ИИ-продавцу — уйти ниже его скрытой минимальной цены. Если модель недоступна или ответила мусором, ход делает сценарная стратегия — демо не падает.

### API

| Метод | Путь | Что делает |
| --- | --- | --- |
| GET | `/api/health` | активный провайдер LLM |
| POST | `/api/session` `{query}` | создать сессию |
| GET | `/api/session/{id}/stream` | SSE-поток событий агента (step, message, result, confirm, turn, price, call_end, done) |
| POST | `/api/session/{id}/confirm` `{kind, approved, data}` | решение клиента: `red_lines`, `consent`, `call` (`data.mode = auto|human`), `price`, `object`, `sign` |
| POST | `/api/session/{id}/seller` `{text}` | реплика живого продавца в режиме `human` |
| GET | `/api/economics?savings_pct=0.03&deals=15000…` | юнит-экономика + сценарии ROI |

## Переключение на GigaChat

В `.env`:

```
LLM_PROVIDER=gigachat
GIGACHAT_CREDENTIALS=<ключ авторизации из личного кабинета, base64>
GIGACHAT_SCOPE=GIGACHAT_API_PERS        # или GIGACHAT_API_B2B / GIGACHAT_API_CORP
GIGACHAT_MODEL=GigaChat-2-Max
GIGACHAT_CA_BUNDLE=/path/to/russian_trusted_root_ca.cer   # сертификат НУЦ Минцифры
```

Если сертификата нет под рукой, для локального демо можно `GIGACHAT_VERIFY_SSL=false`. Код агента менять не нужно: оба провайдера реализуют один `LLMClient`. Отличия API (OAuth-токен на 30 минут, `functions` вместо `tools`, нет `response_format`) закрыты внутри [backend/llm/gigachat.py](backend/llm/gigachat.py).

## Данные

Все объявления, сделки-аналоги и проверки — синтетика (Казань, октябрь 2026). Ставка 16,9% и тарифы — допущения для демо. В проде их заменят база объявлений Домклик, сделки и оценки залогов Сбера, ЕГРН/ФССП/ЕФРСБ и ставка из предодобрения.
