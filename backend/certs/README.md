# Сертификат GigaChat

Публичный Russian Trusted Root CA загружен 01.11.2026 по HTTPS с официального адреса:
https://gu-st.ru/content/lending/russian_trusted_root_ca_pem.crt

Используется только SSL-контекстом клиента GigaChat. Системное хранилище доверия не меняется,
проверка TLS остаётся включённой. Пользовательский `GIGACHAT_CA_BUNDLE` имеет приоритет.

Инструкция провайдера: https://developers.sber.ru/docs/ru/gigachat/certificates
